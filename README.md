# LLM-Based Intelligent Retail Assistant 🤖

## Overview
End-to-end LLM-powered shopping assistant enabling customers 
to query products in natural language and get real-time AI responses.

## Tech Stack
- 🔗 LangChain — conversation chain management
- 🤖 Google Gemini API — LLM response generation  
- 🤗 Hugging Face — semantic similarity matching
- 🗄️ MySQL — real-time product database
- 🎨 Streamlit — interactive web interface
- 🐍 Python

## Features
- Natural language product search
- Multi-turn conversation memory
- Real-time database query handling
- Browser-based interactive interface

## How to Run
1. Clone the repository
   git clone https://github.com/yourusername/llm-retail-assistant
2. Install requirements
   pip install -r requirements.txt
3. Add your Gemini API key in .env file
   GEMINI_API_KEY=your_key_here
4. Run the app
   streamlit run app.py
